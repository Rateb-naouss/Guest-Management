# نظام إدارة وتنظيم ضيوف الزفاف | Wedding Guest Management System

نظام ويب متكامل واحترافي مصمم لإدارة وتنظيم حفلات الزفاف، بطاقات الدعوة، توزيع مقاعد الطاولات مع الفحص الصارم للسعات، إحصائيات الرجال والنساء، وتصدير التقارير إلى Excel باللغة العربية.

---

## 🌟 الميزات الرئيسية (Key Features)

### 1. إدارة سجل الضيوف (Guest Management)
- بطاقة بيانات متكاملة لكل ضيف:
  - الاسم الكامل
  - رقم الهاتف
  - جنس الضيف الرئيسي (ذكر / أنثى)
  - أفراد العائلة المرافقين (ذكور)
  - أفراد العائلة المرافقين (إناث)
  - **الحساب الآلي لإجمالي المجموعة**: `إجمالي المجموعة = عدد الذكور + عدد الإناث + 1 (الضيف الرئيسي)`
  - حالة إرسال الدعوة (تمت الدعوة / لم ترسل)
  - حالة الرد (مؤكد الحضور / معتذر / بانتظار الرد)
  - رقم الطاولة المعين عليها
- منع إدخال الأرقام السالبة (Negative Numbers Prevention) على الواجهة والخادم.
- بحث متقدم بالاسم أو رقم الهاتف، فلترة فورية حسب الجنس وحالة الرد وحالة الدعوة والطاولات، ترتيب متعدد، وتصفح بالصفحات (Pagination).

### 2. تدقيق ومراقبة سعة الطاولات الصارم (Strict Table Capacity Enforcement)
- السعة الافتراضية لكل طاولة هي **10 أشخاص**.
- **التحقق المزدوج (Frontend & Backend)** لمنع أي تجاوز للسعة:
  - على سبيل المثال: إذا كانت الطاولة بها 8 أشخاص ومجموعة الضيف الجديد 3 أشخاص، يتم رفض التعيين آلياً لأن `8 + 3 = 11 > 10` مع إظهار رسالة واضحة:
  > *"لا يمكن تعيين هذا الضيف إلى طاولة 11. سعة الطاولة 10 أشخاص والمتبقي فقط 2 مقاعد."*
- إظهار حالة كل طاولة: فارغة، متاحة، شبه ممتلئة، ممتلئة بالكامل.
- إمكانية تسكين الضيوف مباشرة من بطاقة الطاولة أو نقلهم أو تفريغ مقاعدهم.

### 3. لوحة التحكم والإحصائيات الحية (Real-Time Dashboard)
- إجمالي بطاقات الضيوف وإجمالي الأفراد المتوقعين.
- إحصائيات الحضور الدقيقة:
  - المؤكد حضورهم (أفراد وعائلات).
  - المعتذرون عن الحضور.
  - المعلقون بانتظار الرد.
- **إحصائيات الرجال والنساء (Men & Women Statistics)** المحسوبة آلياً:
  - إجمالي الذكور والإناث.
  - الذكور والإناث المؤكدون.
  - الذكور والإناث المعتذرون.
  - الذكور والإناث بانتظار الرد.
- مراقبة إشغال جميع الطاولات بصيغة:
  - `طاولة 1 — 8 / 10`
  - `طاولة 2 — 10 / 10`
  - `طاولة 3 — 6 / 10`
- مفتاح تبديل سياسة الإشغال: **حساب المؤكدين فقط** أو **حساب جميع المعينين**.

### 4. تصدير التقارير إلى Excel (Excel Export)
تصدير 7 أنواع مختلفة من التقارير بصيغة `.xlsx` مع دعم كامل للغة العربية ومحاذاة RTL:
1. قائمة الضيوف الكاملة (Complete Guest List)
2. الضيوف المؤكدون (Confirmed Guests)
3. الضيوف المعتذرون (Declined Guests)
4. ضيوف بانتظار الرد (No Response)
5. مخطط وتوزيع الطاولات (Table Assignments)
6. إحصائيات الرجال والنساء (Men & Women Statistics)
7. إحصائيات الحضور والغياب الشاملة (Attendance Statistics)

### 5. المصادقة والأمان (Security & Authentication)
- مصادقة المشرف عبر JWT وكلمات مرور مشفرة بـ bcryptjs.
- بيانات الدخول الافتراضية للمشرف:
  - **البريد الإلكتروني:** `admin@wedding.com`
  - **كلمة المرور:** `admin123`
- زر تعبئة تجريبية سريع لتسهيل التقييم والاختبار.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend:** React 19 + TypeScript + Vite + Tailwind CSS + Lucide Icons + Canvas Confetti
- **Backend:** Node.js + Express.js RESTful API
- **Database:** MongoDB Architecture (مع دعم الاتصال الخارجي ومحرك التخزين المحلي المتوافق لحفظ البيانات)
- **Export Engine:** XLSX (SheetJS) مع دعم RTL
- **Styling & Fonts:** خط القاهرة (Cairo) و Plus Jakarta Sans
